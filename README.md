# 文档转知识库

一个将已有问答文档整理为标准 QA 知识库 Markdown 文件的 AI Skill，适用于政策问答、产品 FAQ、业务说明等一问一答的资料。

保留原文的问题、答案、标题和来源信息，仅规范格式，不改写内容。输出文件命名为 `<源文件名>-QA知识库.md`，默认保存到源文档所在目录。

## 使用方式

在支持 Skill 的 AI 工具中加载本目录的 `SKILL.md`，提供源文档并提出需求，例如：

> 请把这份问答文档转换成 QA 知识库。

源文档需使用以下结构，`Q` 和 `A` 各占一行，答案可以跨多行：

```text
# 产品使用问答

Q
如何注册账号？
A
打开首页，点击注册。
按照提示填写信息并提交。
```

目前不支持 `Q: 问题`、`问：`、`Q1.` 等变体标记，也不负责从普通文章中自动生成问答或搭建数据库、检索服务。

## 文件说明

- `SKILL.md`：Skill 的触发条件、转换流程和输出要求。
- `references/qa_format.md`：QA 知识库格式规范。
- `assets/`：源文档与转换结果示例。
- `scripts/parse_qa.py`：可选的 Python 3 解析脚本，无需第三方依赖。

在仓库目录运行以下命令，可预览文档的问答数量和内容：

```bash
python scripts/parse_qa.py 输入文档.md
```

脚本只在终端打印解析预览，不生成最终文件；答案预览最多显示 80 个字符。当前脚本按单行问题解析，不校验 Q/A 标记是否完整配对。
