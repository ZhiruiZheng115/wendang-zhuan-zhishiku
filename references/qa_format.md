# QA 知识库标准格式

本文档定义「文档转知识库」skill 输出的 QA 知识库 Markdown 格式规范。

## 整体结构

一份 QA 知识库由以下部分组成，自上而下：

1. **标题**（可选但有则保留）：一级标题 `#`，例如 `# 第二轮土地承包到期后再延长30年试点工作法律政策问答`。
2. **来源/发布时间信息**（可选）：源文档有则保留，例如 `# 来源：xxx | 发布时间：xxxx-xx-xx`。
3. **问答正文**：若干条 Q/A 对依次排列。

## Q/A 对的标准写法

- `Q` 单独占一行（作为标记行）。
- 紧接着的下一行是**问题正文**（可为多行，但通常为一行）。
- `A` 单独占一行（作为标记行）。
- 紧接着的下一行是**答案正文**（可跨多行，保留内部段落/换行结构）。
- 相邻两个问答对之间用一个空行分隔。

### 示例

```markdown
# 第二轮土地承包到期后再延长30年试点工作法律政策问答
# 来源：吉林省农业农村厅 | 发布时间：2026-06-15

Q
什么是二轮到期延包？
A
二轮到期延包，是指现有承包地在第二轮土地承包到期后由农户继续承包，承包期再延长30年。……

Q
二轮到期延包的主要法律政策依据是什么？
A
主要包括《中华人民共和国民法典》《中华人民共和国农村土地承包法》等。

Q
二轮到期延包总的要求是什么？
A
开展二轮到期延包，一是要坚持延包原则……二是对少数存在承包地因自然灾害毁损等特殊情形……可在个别农户间作适当调整，但要依法依规从严掌握。
```

## 关键规则

1. **Q/A 标记独占一行**：`Q` 与 `A` 各自单独一行，不得与内容同行。
2. **内容紧接标记行**：问题/答案正文位于标记行的下一行。
3. **答案可多行**：答案正文若包含多个段落，保留原有换行结构，不要合并成单行。
4. **不改写语义**：问题与答案正文与源文档保持一致，仅做格式规范化。
5. **空行分隔**：相邻 Q/A 对之间保留一个空行。
6. **标题与来源保留**：源文档顶部的标题、来源、发布时间等信息原样保留在输出文档顶部。

## 输出文件命名

- 规则：`<源文件名>-QA知识库.md`
- 示例：源文件 `tdyb.md` → 输出 `tdyb-QA知识库.md`
